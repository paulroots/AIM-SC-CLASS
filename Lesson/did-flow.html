    The two smart contracts

    Only two contracts run on chain. DIDRegistry answers “which keys does this identity use?” and StatusList answers “is this credential revoked?”. Everything else, including signing and checking signatures, happens off chain. As you step through the animation, the code that runs in that step lights up here.

    The one rule

    Personal data stays with the holder. The chain only answers two questions: which keys does this issuer use, and is this credential revoked?

    Not shown here

    Selective disclosure. SD-JWT and zero-knowledge proofs let the student reveal one claim, such as "has a degree", and keep the rest in the wallet.
