    The one rule

    The page asks, the wallet signs, the node relays, the chain decides. Your private key never leaves the wallet.

    MetaMask or Brave Wallet?

    Both speak the same language (EIP-1193). If both are installed, Brave's "Default Ethereum wallet" setting decides which one answers window.ethereum. Pages that support EIP-6963 can list both.

    New words?
